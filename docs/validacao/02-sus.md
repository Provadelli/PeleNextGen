# SUS (System Usability Scale)

## As 10 afirmações do SUS

1. Acho que gostaria de usar este sistema com frequência.
2. Achei o sistema desnecessariamente complexo.
3. Achei o sistema fácil de usar.
4. Acho que precisaria de ajuda de uma pessoa técnica para usar o sistema.
5. Achei que as funções do sistema estavam bem integradas.
6. Achei que havia muita inconsistência no sistema.
7. Imagino que a maioria das pessoas aprenderia a usar o sistema rapidamente.
8. Achei o sistema muito complicado de usar.
9. Senti-me muito confiante ao usar o sistema.
10. Precisei aprender várias coisas antes de conseguir usar o sistema.

## Fórmula do SUS completo (escala 1 a 5)

Ímpares: nota − 1. Pares: 5 − nota. Soma dos 10 valores × 2,5 (resultado de 0 a 100).

## O que foi aplicado

Aplicamos **só 4 afirmações (Q1, Q2, Q5, Q10) em escala 0 a 10**, uma versão reduzida e adaptada.

Índice reduzido (0–100) = média de Q1/10, (10−Q2)/10, Q5/10, (10−Q10)/10, vezes 100.

**Ressalva:** não comparar com a referência de 68 pontos do SUS completo. Resultado em `04-sus-planilha.csv`
(índice médio 89,2).
